# Marakwet Teachers SACCO Website

A modern, responsive, and user-friendly website for the Marakwet Teachers SACCO located in Kapsowar, Elgeyo-Marakwet County.

## 🚀 Features
- **Responsive Design:** Looks great on mobile phones, tablets, and desktops.
- **Core Services:** Showcases Development Loans, Smart Savings, and Emergency Loans.
- **Loan Calculator:** Allows members to estimate their monthly repayments (at a standard 1% monthly interest rate).
- **Membership Form:** Integrated with Formspree so applications are sent directly to the admin's email.
- **WhatsApp Integration:** A floating WhatsApp button for instant customer support.
- **Location Map:** Integrated Google Maps showing the Kapsowar office location.

## 🛠️ Built With
- **HTML5** - Structure
- **CSS3** - Styling (Custom CSS, no frameworks)
- **JavaScript** - Interactivity (Form handling & Loan Calculator)
- **Formspree** - Backend for the contact form
- **GitHub Pages** - Free hosting
